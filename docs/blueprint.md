# **App Name**: BeastMode

## Core Features:

- User Dashboard: Display current streak, weekly progress, and personal records for gym members.
- Workout Logging: Allow users to log exercises, sets, reps, and weight, including a rest timer.
- Progress Tracking: Visualize progress with a streak calendar, body metrics tracking, and goal progress bars.
- Gym Owner Dashboard: Provide an overview of active users, attendance trends, and revenue.
- Member Management: Enable gym managers to add, edit, and delete members with search and filter options.
- Payment Tracking: Allow gym managers to track fees, mark payments, and view payment history.
- Suggested Exercises: Suggest workouts or variations on exercises to the user, using their current and historical performance as a tool.

## Style Guidelines:

- Primary color: Red (#E60023) to match user requirements. It will bring accents and highlights.
- Background color: Dark gray (#1A1A1A), aligning with the dark theme specified by the user.
- Accent color: Pale red/orange (#F24B0F), for a contrasting element with primary.
- Body and headline font: 'Inter', a grotesque-style sans-serif. Note: currently only Google Fonts are supported.
- Mobile-first, card-based design with bottom tab navigation on mobile and sidebar on larger screens.
- Subtle transitions and micro-animations to enhance user experience.
- Use a set of consistent icons that are easy to understand, modern and sleek, following a red/gray/white aesthetic.
